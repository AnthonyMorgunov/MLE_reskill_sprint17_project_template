# Локальные результаты

Сохраняйте здесь веса моделей и промежуточные результаты. Они остаются локальными и не добавляются в Git. Из этой папки в репозитории хранится только этот файл с описанием.

Таблицы, графики, метрики, примеры и выводы, необходимые для ревью, сохраните в выполненных ячейках соответствующего ноутбука.
