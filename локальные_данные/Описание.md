# Локальные данные

Получите данные у курса. В этой папке должны находиться следующие CSV без переименования:

- `task1_export.csv` — собственная выгрузка SQL для Задания 1: одна запись на наблюдение.
- `task2_export.csv` — собственная выгрузка SQL для Задания 2: одна запись на коммерческий запрос.
- `commercial_descriptions_train_ru.csv` — 4050 обучающих текстов для Задания 3.
- `commercial_descriptions_valid_ru.csv` — 450 валидационных текстов для Задания 3.
- `commercial_descriptions_eval_ids.csv` — 100 идентификаторов из валидационного файла для сравнения продолжений.

Первые два файла создайте самостоятельно в DBeaver. Три текстовых файла выдаются готовыми. Сохраните исходное разделение корпуса; словарь LSTM стройте только по обучающему файлу. Полный протокол Задания 3 приведён в уроке проекта.

Настройте локальный путь в своём ноутбуке. Папка данных находится рядом с папкой ноутбуков, а не внутри неё. Все файлы CSV и параметры подключения остаются локальными и не добавляются в Git.

Имена CSV сохраняйте исходными, на английском языке. Содержимое и названия столбцов не изменяйте.
